# Overseas Source Search

해외 인사이트 기반 블로그 글을 만들 때 사용하는 검색 대상과 검색 절차다. 이 파일은 완성된 인사이트를 제공하는 자료집이 아니다. 주제와 시즌에 맞는 실제 원문을 플랫폼에서 찾아 후보를 비교하고, 선택한 글을 한국 자료와 연결하는 데 쓴다.

## 기본 원칙

- 소스 목록을 본문에 나열하지 않는다. 실제로 사용한 원문만 출처로 남긴다.
- 매번 검색해 현재 주제에 맞는 원문을 고른다. 예전에 저장한 고정 인사이트를 그대로 재사용하지 않는다.
- 후보를 3~5개 찾은 뒤, 가장 구체적인 주장·사례·한국형 연결이 있는 원문 1개를 주출처로 선택한다.
- 풍부함은 출처 개수가 아니라 원문 사건의 전후·행동·전환·한계와 한국형 적용 자료를 연결하는 데서 만든다. 해외 주출처 1개와 한국·1차 보조자료 1~2개면 충분하다.
- 기사형 매체·커뮤니티는 레이더로 사용하고, 숫자·투자·성과·인용은 회사 공식 발표나 1차 자료로 다시 확인한다.
- 미국 제도·세무·법률·지원자격은 한국에 번역하지 않는다. 방법과 사고방식만 가져오고, 한국 공고·통계·법령·시장 자료로 다시 확인한다.

## 검색 절차

### 1. 검색 상황부터 정하기

검색 전에 아래 네 가지를 한 줄씩 정한다.

```text
시즌/콘텐츠 목표:
한국 독자가 처한 구체적 장면:
이번 글에서 바꿀 오해 또는 결정:
독자가 글을 읽고 할 한 가지 행동:
```

예를 들어 비수기 지원사업 콘텐츠라면 `지원하세요`가 아니라 `공고 전에 고객 문제·시장·비용 근거를 준비한다`가 검색 방향이 된다.

### 2. 플랫폼 역할을 고르기

아래에서 주출처 역할 1개와 보조출처 역할 1개를 고른다.

- 원칙·초기 검증: First Round Review, Y Combinator, Paul Graham, Steve Blank, Lean Startup, Strategyzer
- 성장·PMF·B2B·GTM: Bessemer, SaaStr, OpenView, Reforge, Lenny’s Newsletter, MKT1, NFX, Greylock
- 최신 사례·시장 레이더: Sifted, TechCrunch, Crunchbase News, PitchBook, Rest of World, 지역 스타트업 매체
- 시장·비용·조사 방법: SBA, SCORE, MIT OpenCourseWare, U.S. Census, Pew Research, BLS, OECD, World Bank
- 브랜드·제품·고객 경험: Figma, Nielsen Norman Group, Kickstarter Lessons, Shopify, Product Hunt, Hacker News

### 3. 플랫폼 안에서 검색하기

일반 검색어 하나로 끝내지 말고 `site:도메인 + 주제 + 갈등/결정`으로 3~5개 플랫폼을 검색한다.

```text
site:review.firstround.com <topic> <customer problem or first users>
site:ycombinator.com/library <topic> <MVP or first customers>
site:paulgraham.com <topic> <market or users>
site:bvp.com/atlas <topic> <retention or product market fit>
site:strategyzer.com/library <topic> <willingness to pay or customer evidence>
site:leanstartup.co <topic> <experiment or assumptions>
site:sba.gov <topic> <market research or startup costs>
```

한국어 주제를 영어 검색어로 바꿀 때는 직역보다 문제를 쓴다.

```text
고객 검증 → customer discovery / first users / customer evidence
사업계획서 근거 → business plan evidence / market research / startup assumptions
공고 전 준비 → before funding / pre-launch validation / early traction
초기 고객 확보 → first customers / founder-led sales / manual onboarding
시장 규모 → market sizing / target customer / willingness to pay
지원금 사용계획 → experiment roadmap / validation milestones / build measure learn
```

### 4. 후보 원문을 같은 형식으로 기록하기

검색 결과마다 아래만 남긴다. 원문을 열어 확인하기 전에는 후보의 주장을 사실처럼 쓰지 않는다.

```text
원문 제목 / URL:
플랫폼 역할:
발행일:
원문이 실제로 말하는 한 문장(요약):
구체적 사례·데이터·행동·전환·결과:
사례가 성립한 조건과 한계:
원문이 다루는 국가·시장·고객 범위:
한국에 옮길 수 없는 전제:
한국에서 다시 확인할 자료 URL / 확인한 주장:
카드 Hook 후보:
블로그 주제 후보:
```

### 5. 주출처를 고르기

후보끼리 아래 네 가지를 비교한다.

- 주장: 한 문장으로 요약할 수 있는가?
- Story: 시작 상황·행동·전환·결과·한계를 복원할 수 있는가?
- 한국 연결: 한국 창업자가 확인할 문서·행동·숫자로 바꿀 수 있는가?
- 출처 품질: 원문 작성자와 사례 당사자를 확인할 수 있는가?

주출처 1개와 보조출처 1개면 충분하다. 관련 없는 인사이트를 더 넣어 글을 풍성하게 만들지 않는다.

### 6. 한국형 글로 변환하기

```text
해외 원문의 주장
→ 원문 사례가 성립한 조건
→ 한국 창업자가 마주한 다른 조건
→ 한국 공식·1차 자료 또는 독자 자신의 기록
→ 사업계획서 문장·검증 지표·다음 행동
```

해외 원문이 `초기 고객을 수작업으로 확보하라`고 말한다고 해서 한국 지원사업 심사위원이 그것을 요구한다고 쓰지 않는다. 대신 `공고 전 고객 검증 기록을 만들 때 어떤 행동을 남길 수 있는가`로 바꾸고, 실제 공고 평가항목·인터뷰 기록·문의·사전예약·견적·결제 자료를 별도로 확인한다.

## 출처별 주의

- First Round·YC·Paul Graham·Steve Blank: 원칙과 사례의 출발점. 한국 창업자의 현실로 다시 번역한다.
- Bessemer·SaaStr·OpenView·Reforge: 성장·PMF·B2B 지표는 투자자·특정 사업모델 맥락을 표시한다. 한국 기업의 기준치로 복사하지 않는다.
- Sifted·TechCrunch·Crunchbase News·PitchBook·Axios·커뮤니티: 사례 발굴용. 투자금·매출·사용자 수는 회사 발표나 공시로 재검증한다.
- SBA·SCORE·IRS·FTC·Grants.gov·U.S. Census·BLS: 미국 제도와 데이터는 구조만 참고한다. 한국 법률·세무·지원자격으로 번역하지 않는다.
- 유료·부분 유료 자료: 제목과 문제의식만 참고하고 본문을 재현하지 않는다.
- 회사 블로그·투자사 자료: 회사 또는 투자사의 주장으로 표시한다. 독립적인 성과 증명처럼 쓰지 않는다.

## 후보 선별 출력

초안 전에 반드시 아래 결과를 만든다.

```text
검색 주제:
검색한 플랫폼:
후보 원문 3~5개:
선택한 주출처:
선택한 보조출처:
주출처의 핵심 주장:
한국형으로 바꿀 독자 장면:
한국에서 확인할 자료:
제목/Hook 후보:
본문에 넣을 사례 흐름:
한국형 작업 예시:
적용하지 말아야 할 경우:
주장별 실제 확인 URL:
```

이 출력이 없으면 해외 인사이트 기반 초안을 시작하지 않는다. 검색 결과가 주제와 맞지 않으면 다른 플랫폼 역할로 다시 검색하고, 그래도 없을 때만 `해외 인사이트 미확인`이라고 표시한 국내형 글로 분리한다.

원문과 한국 자료를 혼동하지 않는다. 각 URL을 실제로 열어 제목·도메인·본문의 지지 범위를 확인하고, 확인하지 못한 URL은 출처로 쓰지 않는다. 한국의 공고일·지원금·자격·평가항목은 반드시 한국 공식 또는 해당 기관의 1차 URL로 확인한다.
